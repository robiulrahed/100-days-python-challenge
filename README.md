# Day 1 — Environment Setup & Hello World
### Practice Problems & Solutions

This folder contains solutions to the 7 practice problems from **Day 1** of the
**100 Days of Python Challenge**, covering `print()`, string basics, escape
characters, comments, and debugging.

---

## Problem 1 — Basic Print
**File:** [`problem1_basic_print.py`](./problem1_basic_print.py)

Prints name, age, and city using three separate `print()` statements.
Demonstrates that text needs quotes while numbers don't.

## Problem 2 — Multi-line Output
**File:** [`problem2_multiline_intro.py`](./problem2_multiline_intro.py)

A short self-introduction written across multiple `print()` calls, showing
that each `print()` automatically starts a new line.

## Problem 3 — Special Characters
**File:** [`problem3_special_characters.py`](./problem3_special_characters.py)

Shows two ways to format output: using `\t` (tab) across multiple
`print()` calls, and using `\n` (newline) inside a single `print()` call.

## Problem 4 — Comments
**File:** [`problem4_comments.py`](./problem4_comments.py)

Demonstrates using `#` to add comments that explain code without affecting
the program's output.

## Problem 5 — ASCII Art
**File:** [`problem5_ascii_art.py`](./problem5_ascii_art.py)

Prints a simple triangle pattern manually with `print()`, since loops
haven't been introduced yet (coming on Day 11).

## Problem 6 — Debug Challenge
**File:** [`problem6_debug_challenge.py`](./problem6_debug_challenge.py)

Identifies and fixes a `SyntaxError` caused by a missing closing quotation
mark in a `print()` statement.

## Problem 7 — Terminal Practice
**File:** [`problem7_terminal_practice.py`](./problem7_terminal_practice.py)

Documents the `python3 --version` and `pip3 --version` terminal commands
used to confirm Python is installed correctly.

---

### 🔑 Key Concepts Practiced
- `print()` function
- Strings and quotation rules
- Escape characters: `\n`, `\t`
- Comments (`#`)
- Basic syntax error debugging
- Terminal/CLI basics
