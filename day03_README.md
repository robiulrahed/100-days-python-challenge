# Day 3 — Basic Data Types (int, float, string, bool)
### Practice Problems & Solutions

This folder contains solutions to the 7 practice problems from **Day 3** of the
**100 Days of Python Challenge**, covering Python's core data types, the
`type()` function, and type casting.

---

## Problem 1 — Basic Data Type Creation
**File:** [`day03_problem1_basic_types.py`](./day03_problem1_basic_types.py)

Creates one variable of each core type (str, int, float, bool) and
prints each along with its type.

## Problem 2 — Guess the Data Type
**File:** [`day03_problem2_guess_type.py`](./day03_problem2_guess_type.py)

Verifies data type predictions with `type()`, highlighting the common
trap of a number written inside quotes being a string, not an int.

## Problem 3 — String to Int Conversion
**File:** [`day03_problem3_string_to_int.py`](./day03_problem3_string_to_int.py)

Converts a numeric string to an integer with `int()` before using it
in a calculation.

## Problem 4 — Type Casting Practice
**File:** [`day03_problem4_type_casting.py`](./day03_problem4_type_casting.py)

Converts an int to float and string using `float()` and `str()`,
showing that conversions return new values rather than modifying the original.

## Problem 5 — String + Number Error
**File:** [`day03_problem5_string_number_error.py`](./day03_problem5_string_number_error.py)

Demonstrates the `TypeError` from adding a string and an int directly,
then fixes it with explicit type conversion.

## Problem 6 — Debug Challenge
**File:** [`day03_problem6_debug_challenge.py`](./day03_problem6_debug_challenge.py)

Fixes a `NameError` caused by writing `true` instead of `True`.

## Problem 7 — Real-world Application
**File:** [`day03_problem7_report_card.py`](./day03_problem7_report_card.py)

Builds a student report card program where a boolean value is
calculated from a comparison rather than typed in directly.

---

### 🔑 Key Concepts Practiced
- Core data types: `int`, `float`, `str`, `bool`
- Checking types with `type()`
- Type casting with `int()`, `float()`, `str()`
- Common type-related errors (`TypeError`, `NameError`) and fixes
- Booleans produced by comparisons
