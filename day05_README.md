# Day 5 — String Formatting (f-strings) & Indexing
### Practice Problems & Solutions

This folder contains solutions to the 7 practice problems from **Day 5** of the
**100 Days of Python Challenge**, covering f-strings, expressions inside
f-strings, and both positive and negative string indexing.

---

## Problem 1 — f-string with Two Variables
**File:** [`day05_problem1_fstring_two_vars.py`](./day05_problem1_fstring_two_vars.py)

Builds a sentence from two variables using an f-string instead of
manual string concatenation.

## Problem 2 — f-string with Calculation
**File:** [`day05_problem2_fstring_calculation.py`](./day05_problem2_fstring_calculation.py)

Runs a multiplication directly inside an f-string's `{ }` placeholder.

## Problem 3 — Basic Indexing
**File:** [`day05_problem3_basic_indexing.py`](./day05_problem3_basic_indexing.py)

Retrieves the first character, last character, and a middle
character of a string using positive indexing.

## Problem 4 — Negative Indexing
**File:** [`day05_problem4_negative_indexing.py`](./day05_problem4_negative_indexing.py)

Retrieves the last three characters of a string counting backward
from `-1`.

## Problem 5 — First Letter of User's Name
**File:** [`day05_problem5_first_letter_input.py`](./day05_problem5_first_letter_input.py)

Combines `input()`, indexing, and f-strings to display the first
letter of a name the user types in.

## Problem 6 — Debug Challenge
**File:** [`day05_problem6_debug_challenge.py`](./day05_problem6_debug_challenge.py)

Fixes a bug where a missing `f` prefix causes `{temperature}` to
print literally instead of showing the variable's value.

## Problem 7 — Username Generator
**File:** [`day05_problem7_username_generator.py`](./day05_problem7_username_generator.py)

A real-world mini program that builds a username from the first
three letters of a name plus a birth year, using indexing and
f-strings together.

---

### 🔑 Key Concepts Practiced
- Writing and using f-strings (`f"...{variable}..."`)
- Running expressions/calculations inside f-strings
- Positive indexing (starts at 0)
- Negative indexing (starts at -1, counts from the end)
- Combining indexing with f-strings in realistic mini programs
