# Day 4 — Taking User Input & Type Casting
### Practice Problems & Solutions

This folder contains solutions to the 7 practice problems from **Day 4** of the
**100 Days of Python Challenge**, covering the `input()` function and
converting user input to numeric types.

---

## Problem 1 — Basic Input & Greeting
**File:** [`day04_problem1_basic_input.py`](./day04_problem1_basic_input.py)

Takes a name as input and builds a greeting message using string
concatenation.

## Problem 2 — Age After 10 Years
**File:** [`day04_problem2_age_after_years.py`](./day04_problem2_age_after_years.py)

Converts input age to int so it can be used directly in a math
calculation.

## Problem 3 — Two Numbers - Sum, Difference, Product
**File:** [`day04_problem3_two_numbers_math.py`](./day04_problem3_two_numbers_math.py)

Takes two float inputs and performs multiple arithmetic operations
on them.

## Problem 4 — Name and City Sentence
**File:** [`day04_problem4_name_city_sentence.py`](./day04_problem4_name_city_sentence.py)

Combines two string inputs into a single readable sentence.

## Problem 5 — Total Price Calculator
**File:** [`day04_problem5_total_price.py`](./day04_problem5_total_price.py)

Mixes float and int input types in a single calculation to find a
total price.

## Problem 6 — Debug Challenge
**File:** [`day04_problem6_debug_challenge.py`](./day04_problem6_debug_challenge.py)

Fixes a bug where two numbers get concatenated as text ("53") instead
of added as numbers (8), due to missing type conversion.

## Problem 7 — Simple BMI Calculator
**File:** [`day04_problem7_bmi_calculator.py`](./day04_problem7_bmi_calculator.py)

A real-world calculator that takes weight and height as input and
computes BMI using a formula.

---

### 🔑 Key Concepts Practiced
- Reading user input with `input()`
- Understanding that `input()` always returns a string
- Converting input to `int` or `float` for calculations
- The difference between string concatenation and numeric addition
- Building small interactive programs
