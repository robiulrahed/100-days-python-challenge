# Day 2 — Variables & Rules for Naming Variables
### Practice Problems & Solutions

This folder contains solutions to the 7 practice problems from **Day 2** of the
**100 Days of Python Challenge**, covering variable creation, naming rules,
multiple assignment, and value updates.

---

## Problem 1 — Basic Variable Creation
**File:** [`problem1_basic_variables.py`](./problem1_basic_variables.py)

Creates string, float, and boolean variables and prints each one,
showing how Python infers data types automatically.

## Problem 2 — Naming Rule Spotting
**File:** [`problem2_naming_rules.py`](./problem2_naming_rules.py)

Identifies valid and invalid variable names, explains why each is
valid/invalid, and shows corrected versions of the invalid ones.

## Problem 3 — Multiple Assignment
**File:** [`problem3_multiple_assignment.py`](./problem3_multiple_assignment.py)

Assigns three different values to three variables in a single line
using comma-separated assignment.

## Problem 4 — Value Update
**File:** [`problem4_value_update.py`](./problem4_value_update.py)

Updates a variable's value based on its own previous value, printing
the state before and after the change.

## Problem 5 — Same Value, Multiple Variables
**File:** [`problem5_same_value_multiple_vars.py`](./problem5_same_value_multiple_vars.py)

Assigns the same value to three variables at once using chained
assignment, contrasted with Problem 3's different-values approach.

## Problem 6 — Debug Challenge
**File:** [`problem6_debug_challenge.py`](./problem6_debug_challenge.py)

Fixes a `SyntaxError` caused by a variable name starting with a digit.

## Problem 7 — Real-world Application
**File:** [`problem7_product_info.py`](./problem7_product_info.py)

Builds a small product info program that calculates a total price
from stored variables, demonstrating a practical use of variables.

---

### 🔑 Key Concepts Practiced
- Variable creation and assignment
- Variable naming rules and conventions
- Multiple assignment (different values vs. same value)
- Reassigning variables based on their own value
- Using variables in calculations
