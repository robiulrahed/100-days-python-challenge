# Day 7 — Arithmetic & Assignment Operators
### Practice Problems & Solutions

This folder contains solutions to the 7 practice problems from **Day 7** of the
**100 Days of Python Challenge**, covering all arithmetic operators
(`+ - * / // % **`), assignment shortcuts (`+= -= *= /=`), and
operator precedence.

---

## Problem 1 — All Arithmetic Operators
**File:** [`day07_problem1_all_operators.py`](./day07_problem1_all_operators.py)

Takes two numbers and demonstrates every basic arithmetic operator
on them in one program.

## Problem 2 — Even or Odd Checker
**File:** [`day07_problem2_even_odd_checker.py`](./day07_problem2_even_odd_checker.py)

Uses `%` to determine whether a number is even or odd - the most
common real-world use of the modulus operator.

## Problem 3 — Power Calculator
**File:** [`day07_problem3_power_calculator.py`](./day07_problem3_power_calculator.py)

Uses `**` to raise a base number to a given exponent.

## Problem 4 — Seconds to Minutes and Seconds
**File:** [`day07_problem4_seconds_converter.py`](./day07_problem4_seconds_converter.py)

Uses `//` and `%` together to split a total seconds count into
minutes and remaining seconds.

## Problem 5 — Balance Tracker with Assignment Operators
**File:** [`day07_problem5_balance_tracker.py`](./day07_problem5_balance_tracker.py)

Uses `+=` and `-=` to update a running balance step by step.

## Problem 6 — Debug Challenge (Operator Precedence)
**File:** [`day07_problem6_debug_challenge.py`](./day07_problem6_debug_challenge.py)

Walks through Python's order of operations (exponents before
multiplication before addition) to correctly predict an expression's
result.

## Problem 7 — Bill Splitter
**File:** [`day07_problem7_bill_splitter.py`](./day07_problem7_bill_splitter.py)

A real-world program that splits a bill evenly among a group using
`//`, and finds the undistributed leftover amount using `%`.

---

### 🔑 Key Concepts Practiced
- Basic arithmetic: `+ - * /`
- Floor division `//` vs regular division `/`
- Modulus `%` for remainders and even/odd checks
- Exponentiation `**`
- Assignment shortcuts: `+= -= *= /=`
- Operator precedence (order of operations)
